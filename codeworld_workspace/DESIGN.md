# 主干设计与当前完成边界

## 目标与范围

将 RCWM 的生成程序编译成通用 coding agent 可以读取、编程查询和维护的文件工作空间。
支持固定形状刚体、静态背景、操作后的位姿更新，以及 Agent 显式发布部件几何和更新部件变换。不内置关节估计器、形变模型或极精细接触控制；允许 agent 维护动作传播得到的预测位姿。
当前组件是世界接口，不负责另建 agent 推理循环。

## 内容与唯一依据

1. 原始程序、参数、输入、Three.js 依赖整体快照，保留源信息。
2. 执行后的场景树：节点路径、名称、userData、局部与世界变换、对象归属。
3. 每个对象独立局部坐标 GLB；保留完整生成网格及材料。几何以实际执行结果为准。
4. 对象索引保留所有根声明；候选表面、语义和不确定性仍是重建声明，不自动认证。
5. 当前状态单独存放，统一使用米、行主序 T_W_object。原参数中的位姿仅表示初始声明。
6. 任务目标、约束、成功标准、执行接口独立存放；未给定操作目标时保持空，不自行执行动作。
7. 查询可访问全 mesh、当前部件树、点变换、包围盒、点到三角面距离；agent 可以自行编写其他计算。

## 与 Three.js 的绑定

执行窗口先等待异步 build 完成，再采集 matrixWorld 与网格；对代码/参数/资产检查导出期间是否变化。
将世界坐标导出的对象变换回其实际局部坐标，以逐顶点双向最近距离及边界往返检查验证。
源快照、对象元数据和几何属于一个固定 geometry_revision；可显式调用 verify_binding 审计，不在读取或动作前强制运行。

维护状态使用：当前 T_W_object × 初始对象坐标下的固定几何。
部件变换使用：当前对象变换 × 初始对象变换的逆 × 初始部件世界变换。
这样移动刚体时部件、完整网格与查询保持一致，且不会重复施加父节点和子节点声明的位姿。

不反向猜测任意 JavaScript 中哪一行赋值应被改写。初始生成源码保留，当前世界使用独立位姿覆盖层。
更改原始重建仍需独立源运行；另外可用 publish_parts 为单个物体发布不可变部件资产覆盖层，保留原始绑定。update_parts 只改部件变换和自由参数，查询使用最新覆盖层。没有自动重建或跨形状状态推断。

## Codex 的工作方式

把工作目录提供给 Codex。入口是 AGENTS.md → task/task.json → 对象索引 → 所需对象/源码。
Codex 在 work/ 写 Python 并导入 bundled World；可以直接读取 mesh 和源码，不受固定技能列表限制。
查询返回状态版本供 agent 使用；执行端不强制绑定世界版本。
图像和网格文件按需读取，不将完整场景 JSON 每轮塞入提示词。

## 更新规则

- 假设移动：fork 场景分支，set_hypothesis，不覆盖真实状态。
- 当前状态：World.update 直接提交位姿，标明 action_prediction、agent_estimate 或 observation_estimate；证据引用可选。
- 状态和历史原子写入；expected_revision 是可选的并发写入保护。
- 几何、源码与状态更新均不等于执行机器人动作。机器人连接在 task 中明确配置。
- 外部位姿报告是估计；本模块不伪装成跟踪器，不把文件存在当作实际感知准确性证明。

## 实际验收

正式使用 LIBERO Astra 原有重建场景验证（DeepSeek 仅保留为先期独立检查）：源码绑定、11 个对象局部几何往返、世界空间查询、
假设分支移动碗、其他对象不变、原当前状态不变、更新后 GLB 导出。
单元检查覆盖位姿更新、分支隔离、可选并发版本条件和显式源绑定审计。
这些验证证明组件可运行，不证明机器人完成任务或原重建精度达标。

机器人已通过独立直接 I/O 连接。感知方法由 Codex 选择，当前没有强制跟踪器或额外 agent 调度器。

## 部件覆盖层接口

- `publish_parts(object_id, parts, parameters=..., basis=..., evidence=...)`：将指定物体替换为一组部件，包含固定主体。每个部件给出本地 mesh 路径及 `T_object_part`。资产复制到新版本目录，原始重建保持不变。
- `update_parts(object_id, transforms, parameters=..., basis=...)`：只更新指定部件的刚体变换及自由参数，不调用模型、拟合器或渲染器。轴、运动学、角度/位移到变换的计算由 Codex 自己编写。
- 参数仅是描述性状态，不会隐式驱动几何；需要同时提交变换。
- `part_mesh` 返回部件当前世界几何；`mesh/parts/bounds/nearest_surface/export_scene` 使用当前装配。整体位姿更新保留部件状态。
- 状态修订与历史记录原子提交；假设分支隔离；显式 verify_binding 同时检查已发布的部件资产。
- 观察频率、是否局部补建及计算预算由 Agent 决定，没有每动作必须重建的规则。
